Site de vente d'objets de seconde main basé sur le look de Ricardo.ch. Site de E-commerce en Java, JSTL 1.2, EL, *.jsp, *.css avec tomcat 8.5 et mysql-server 8.0.32.
Dans ce site, l'utilisateur peut :
- Accepter ou non les cookies
- Regarder la liste d'objets de second main à vendre
- Se créer un compte utilisateur
- Accéder à ses paramètres
- Créer une annonce avec upload des 3 fichiers images
- Il doit créer un mot de passe fort
- S'il perd son mot de passe, il reçoit un email pour réinitialiser son mot de passe
- Choisir des objets à acheter et les payer (a noter qu'il n'y a pas de vrai interface de paiement en ligne.
